## BSF 接口、位序与配置依据

本地模块说明第 1 页指明 TTP229-BSF/SSOP28；模块原理图 U1 的 SDO=12、SCL=13，与 B 型一致。说明照片将 SCL/SDO 标成 I²C，但 B 型没有该接法所需的 SDA；通用 TTP229 中英文手册混有其他封装与接口，不能叠加解释为 BSF 的能力。

依据[厂家 BSF 手册 V1.1](https://www.tontek.com.tw/uploads/product/97/TTP229-BSF_V1.1_EN.pdf)第 7～8 页，实现 **始终轮询**的专用两线协议：SCL 默认高空闲，下降沿后依次呈现 D0～D15，分别对应 TP0～TP15。低相位末端采样已同步数据，然后拉高 SCL。原始低表示按下，读取器统一为高表示按下；16 位收齐才更新 `keys_state`。这不是 I²C 地址/ACK 事务，也没有采用通用 SPI 控制器。

| 参数/接口 | 默认值与含义 |
| --- | --- |
| STARTUP_CYCLES | 13500000 拍，0.5 秒；此时不读键，不满足运行期 10 ms 定义 |
| SCL_HALF_CYCLES | 135 拍，5 µs；100 kHz，处于手册频率范围内 |
| FRAME_GAP_CYCLES | 81000 拍，3 ms 高空闲，给典型 2 ms 超时留裕量 |
| 一帧时长 | 第一次下降沿到最后位采样为 31×135=4185 拍，即 155 µs |
| 连续帧周期 | 85185 拍，即 3.155 ms |
| keys_valid | 第一次完整帧后保持 1；复位清零 |
| keys_commit | 完整帧提交时单个 clk 脉冲，供时间边界观察 |

手册对 DV/Tw 的图示与外围传播时间没有给出完整最坏条件；本实现依据手册允许的持续轮询方式，不把 DV 当单独时钟或新时钟域。行为模型采用 200 ns 数据传播延迟，不冒充芯片最大传播时间；线长、SDO 建立保持、DV 与轮询相互作用仍需实物示波器/逻辑分析仪确认。

SDO 为 CMOS 推挽输出。约束选择 UP 是因为默认空闲高、拔线时应趋向无按键；不沿用旧输入 DOWN，也不将其当 I²C 开漏总线。`keys_valid` 仅表示收满一帧，**不能检测模块缺失或校验数据正确**。无 ACK/CRC 的协议无法识别全部合法电平形式的坏帧；中断后正常完整帧可恢复，FPGA 复位也会丢弃半帧并通过长空闲重新对齐外设。

模块必须断电配置 **16 键和全多键**：TP2/KYSEL 通过高阻网络接地，TP3/SKMS1 与 TP4/SKMS0 也都通过高阻网络接地。不能把触摸电极直接短接 GND。按所附模块原理图，P1 的 3-4 对应 TP2、1-2 对应 TP3；P2 的 7-8 对应 TP4。实物焊盘方向及电阻是否安装仍需断电通断核对，不能只按照片左右方向插跳帽。TP1 保持默认低有效；TP5 可选 64 Hz 唤醒。硬件配置尚未实测确认。

按模块原理图，面板 1～16 分别连 K0～K15/TP0～TP15，而不是仅凭串行第一个 bit 猜测面板编号。首次硬件测试仍逐键复核。

| 触摸通道 | 所附原理图的面板编号 | 功能 |
| --- | --- | --- |
| TP0～TP7 | 1～8 | MIDI 60、62、64、65、67、69、71、72 |
| TP8 | 9 | 音色切换 |
| TP9、TP10 | 10、11 | 音量增加、减少 |
| TP11、TP12 | 12、13 | 上弯音、下弯音 |
| TP13～TP15 | 14～16 | 预留，完整读取但不触发事件 |

## 数字延迟边界与验收定义

仅在正常运行、启动等待完成、输入保持稳定的条件下评估 FPGA 侧 ≤270000 拍。TTP229 的电容扫描/检测/唤醒和声学时间不计入该数字指标；启动 0.5 秒、复位及无限持续抖动不具有同一运行期延迟保证。

同时报告两个输入时点，防止隐藏轮询：

- `available`：模型已获得新数字按键状态的时刻，可位于本帧快照刚锁定之后；**计入错过本帧的轮询等待**。这比新数据实际出现在 SDO 更早，是更保守的边界。
- `wire`：携带新快照的第一位 SDO 帧数据在模型中稳定的时刻（下降沿后 200 ns）。控制通道自身的位通常更晚，因此以首帧位计时仍保守。
- A：available/wire → reader 完整位图提交。
- B：提交 → 音符事件、PCM → 已验证完整 I²S 左字的 MSB 时刻。
- C：available/wire → 相应外部 I²S MSB。
- D：提交 → 音色/音量/弯音配置及真实受影响 PCM → 外部 I²S MSB。

MSB 时间在独立接收器验完完整 16 位字之后回溯记录，不能用内部 valid 替代外部输出。测试含四音符同按、音符加控制同帧、五种控制和六个读帧/音频相位偏移；并保持原整机数学波形、包络、混音及事件/分配器参考。

最差采集界：`旧帧剩余4185 + 帧间81000 + 新帧4185 + 余量8 = 89378` 拍。全相位保守控制界：

`89378 + (135000+3) + 3×576 + 128 + 36 = 226273` 拍，约 **8.380481 ms**，距 10 ms 尚余 **43727 拍，约 1.619519 ms**。该界包含读帧/轮询、稳定滤波、相位改变后的波形输出、PCM 管线、pending 装载和外部 MSB 等待。有限案例的最大测量值不能代替这个全相位界；同样，未测量的外部传播条件也不能由这个仿真界保证。

BSF 手册的典型工作状态响应为 8 键约 16 ms、16 键约 32 ms，睡眠唤醒还会增加等待。因此 **手指触摸到实际声音 ≤10 ms 尚未证明，不能据 FPGA 数字指标宣称整机触摸总延迟达标**。
