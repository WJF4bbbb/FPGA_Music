# TTP229 模块接口与 FPGA 接线评估

日期：2026-10-28（Asia/Shanghai）。本次为资料与源码核对，仅新增本文；没有修改 RTL、约束或执行烧写。实物芯片丝印、跳帽状态与开发板 PCB 版本尚未核实。

## 1. 接口结论与证据

按提供资料中的 TTP229-BSF / TTP229B 模块，应使用 **SCL + SDO 专用两线串行接口**，不是标准 I²C。模块也支持 8 键模式的八路并行直接输出；16 键模式只能串行输出。因此，减少 FPGA 引脚占用需要主动选择串行接法，并不是模块只有串行接口。

资料存在混用，不能把所有 PDF 的功能叠加到同一芯片上：

| 资料 | 已核对的内容 | 对工程的含义 |
| --- | --- | --- |
| `documents/7-元器件模块资料（新）/A1-6-3L/TTP22916路触摸模块使用说明.pdf` 第 1 页 | 标注 TTP229-BSF、SSOP28 | 应按 B 型芯片核对 |
| 同一说明第 4 页 | 照片丝印是 SCL、SDO，但箭头误标为 I2C | 不能据箭头选 I²C 驱动 |
| `TTP229B原理图.pdf` 第 1 页 | U1 为 28 脚；SDO=12、SCL=13；P3 引出这两根线，没有 SDA | 电路与 B 型串行接口相符 |
| `TTP229中文手册.pdf` 与 `触摸IC_TTP229手册.pdf` | 为通用 TTP229 资料，含 SDA、SLSERT、地址脚等 | 这些功能不能直接套用到 BSF 模块 |

[通泰官方型号表](https://www.tontek.com.tw/product/product2?idx=97&lang=)也将 BSF 列为 TT SPI/Direct，将 LSF 列为 I2C/Direct。这里的 TT SPI 是厂商专用两线接口，不应直接当作通用 SPI 控制器使用。具体引脚与时序见[官方 BSF 手册](https://www.tontek.com.tw/uploads/product/97/TTP229-BSF_V1.1_EN.pdf)第 3、7、8 页。

若实物丝印实际为 LSF 或其他型号，应重新核对；目前结论针对目录内说明与原理图所描述的 B 型模块。

## 2. 建议采用的工程结构

第一阶段保持现有 8 个音符，采用 **8 键、全多键有效、两线串行读取**。16 块触摸区域不代表必须启用 16 键模式。8 键模式使用 TP0～TP7，对应原理图的面板 1～8。

建议保留现有滤波模块，新加协议读取模块：

```text
模块 SDO -> ttp229_reader -> 8 位高有效按键快照
                 |                   |
                 +-> 模块 SCL        v
                              sensor_frontend
                                     |
                                     v
                              note_event -> 现有音频链
```

新模块在 27 MHz 的 clk 域内用计数器与时钟使能产生 SCL；SDO 经同步后，在数据稳定窗口采样。默认串行低有效，读回后归一化为按下=1。D0 对应 TP0，完整收完一帧后一次性提交位图，禁止边移位边更新音符状态。还需处理上电等待、复位、帧间隔及超时后的重新对齐。

初期可用约 100 kHz SCL；默认 SCL 空闲高，按手册低有效时序读 8 位。降低串行读出耗时不会加快芯片内部触摸扫描。若模块已设成 16 键，必须相应读完整 16 位，再选择供当前八音符使用的位；不能混用 8/16 位帧配置。

## 4. 引脚分配与可释放引脚

建议复用现有两根相邻引脚：

| FPGA 物理引脚 | 当前端口 | 建议用途 |
| --- | --- | --- |
| 27 | key_raw[2] | ttp_scl，FPGA 输出到模块 |
| 28 | key_raw[3] | ttp_sdo，FPGA 接收模块数据 |
| 25、26、29、30、31、77 | 其余六路 key_raw | 从传感器接线与端口约束中释放 |

这是 **8 根信号线减少为 2 根，净释放 6 个 FPGA I/O**，另需 VCC 和 GND。现有固件尚未变更，不能现在就把 27 当成 SCL 输出使用。

按[官方 3921 Rev 1.30 原理图](https://dl.sipeed.com/fileList/TANG/Nano_20K/2_Schematic/Tang_Nano_20K_3921_Schematics.pdf)第 2、3、6 页核对：27/28 属于 3.3 V 供电的 Bank5，接 LCD B7/B6 和排针 J6-8/J6-9；它们与独立的 HDMI DVI_TX2 信号不是同一网络。此方案不连接 LCD，调试期间也保持 HDMI 断开。

“释放”只代表本工程不再占用：25 仍连 LCD HS/HDMI CEC 网络，26 仍连 LCD VS/HDMI HPD 网络及板载下拉；29/30/31/77 仍与 LCD 共用。不能把它们全部重新标为无负载 GPIO。

## 5. 下一步接线与模块配置

以下排针序号依据 3921 Rev 1.30；实物板版本一致后再采用，优先按板上 GPIO 丝印核对。FPGA 物理引脚 27 不等于排针第 27 针。

| 模块端 | FPGA 板端 | 方向/说明 |
| --- | --- | --- |
| VCC | 3V3，参考 J6-19 | 模块使用 3.3 V 供电 |
| GND | GND，参考 J6-20 | 共地 |
| SCL | GPIO27，参考 J6-8 | FPGA -> 模块 |
| SDO | GPIO28，参考 J6-9 | 模块 -> FPGA |
| OUT1～OUT8 | 不接 FPGA | 本方案使用串行位图 |

本地模块原理图将这四根线标为 P3-12=VCC、P3-11=GND、P3-10=SCL、P3-9=SDO。实物按丝印接线，不凭照片左右方向计数。不要用 5 V 给模块供电后将 SDO 直接接到 3.3 V FPGA 输入；串行 SDO 是 CMOS 推挽输出，不需要照搬 I²C 的 SDA 开漏接法和上拉网络。旧八路输入的外部下拉也不沿用到新串行接口。

模块配置先断电，再通过板上已有高阻电阻的跳帽网络选择：

| 功能脚 | 第一阶段建议 |
| --- | --- |
| TP2 / KYSEL | 保持默认 8 键；若选择 16 键则读取器必须一起改成 16 位帧 |
| TP3 / SKMS1、TP4 / SKMS0 | 两者都通过高阻电阻接 GND，选择全多键；默认单键无法提供和弦输入 |
| TP1 / SAHL | 保持默认串行低有效，FPGA 解码为高有效位图 |
| TP5 / WPSCT | 可选 64 Hz 睡眠唤醒，需与实物跳帽/电阻网络核对 |

本地原理图中的 P1：1-2 对应 TP3、3-4 对应 TP2、5-6 对应 TP1、7-8 对应 TP0；P2：7-8 对应 TP4、5-6 对应 TP5、3-4 对应 TP6、1-2 对应 TP7。该编号只适用于所附原理图；实物跳帽必须用走线或断电通断测量确认。跳帽用于接入现有高阻电阻，不能把触摸电极直接短接到地。通用中文手册中 TP5/TP6 的括号功能名有互换，按 BSF 手册引脚号和功能表确认。

接线与 RTL 更新后的检查顺序：先保持功放关闭观察串行波形，确认上电约 0.5 秒内不触摸；验证空闲全松开、每个键独立映射、同时四键、逐键松开；检查 SCL 和 SDO 幅度与采样窗口，再接入完整音频回归并上板测量触摸到音频的总延迟。

## 6. 延迟结论

BSF 手册第 5、8 页给出工作状态输出响应的典型值：8 键约 16 ms，16 键约 32 ms；睡眠唤醒还有额外等待。这些是芯片典型值，不是实测值或保证上限。

因此，这块模块可以用于电容触摸与多键演示，但目前不能承诺满足“手指触摸到声音不超过 10 ms”。历史测试只覆盖 FPGA 的原始数字输入到 I²S；新测试应分别报告模块延迟、串行读帧等待、FPGA 音频链延迟。若 10 ms 是硬性整机指标，应评估更快的传感器方案，而不是仅提升 SCL 频率。
