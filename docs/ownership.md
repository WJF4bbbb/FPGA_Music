# 分工与开发规划

依据：接口合同见 [interfaces.md](interfaces.md)，对应根目录《模块接口规范》V1.1（2026-10-21）。旧规划与本合同冲突时，以V1.1为准。本文描述待完成工作，不代表RTL已实现或验证通过。

## 1. 本轮范围

采用27MHz主时钟直接分频：BCLK=1.5MHz，实际采样率46875Hz，每帧576个clk周期。默认4声部，参数支持4或8声部；16位有符号单声道样本复制到左右声道，采用标准Philips I2S。

活动RTL共11个：top、audio_timing、i2s_tx、test_mode、voice_alloc、osc、adsr、mixer、sensor_frontend、control_panel、note_event。clk_gen只保留为备用PLL封装，不例化、不加入当前仿真或综合清单；本轮不开发PLL方案。

## 4. 集成时必须守住的时序

- 所有内部逻辑只用clk；外部复位由top异步拉低、至少两级同步释放。子模块统一接core_rst_n。
- test_enable在启动前设置并保持到启动完成；top同步并锁定模式，锁定前保持其他模块复位；运行时忽略模式变化，换模式需复位。
- 事件仅在evt_valid与evt_ready同时为1时消费；背压期间整条事件保持，未选事件源ready=0。
- frame_load与frame_tick同时出现在下降沿索引31。该沿发送旧帧右声道LSB，并装载已完成样本；下一次索引0发送新帧左声道MSB。
- osc由frame_tick启动；adsr由wave_valid处理数据；mixer由全路voice_valid处理数据。ADSR和mixer的frame_tick用于控制快照。
- 同沿到达的sample_valid不能绕过pending成为本次装载结果；首次装载零不计欠载，后续缺样保留旧帧并饱和计数。
- 第0声部放总线低位；每路样本取出后按signed扩展。静音声部仍每帧提交一次valid，所有声部延迟一致。

## 6. 交付检查

合并前核对接口合同、top接线、源列表、仿真入口和约束是否一致。不得用rtl通配符把clk_gen或旧模块意外加入。B报告固定流水线延迟；C报告滤波和事件排队延迟；A测量从原始输入到对应I2S输出的最坏延迟，注明测量起终点及条件。缺少板测证据时，整机验收保持待完成。
